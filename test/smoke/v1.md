# fvmux v1 — Smoke Checklist

Run inside an outer tmux on macOS or Linux. Each box ticks when the
expected behaviour matches the description.

## Launch & first-run

- [ ] `./fvmux` launches without errors.
- [ ] If `~/.config/fvmux/state.toml` is absent: splash appears, welcome
      dialog asks the user to acknowledge.
- [ ] After welcome, an empty session opens with one window running
      `$SHELL`.
- [ ] Subsequent launches skip the splash.
- [ ] `./fvmux -no-splash` skips the splash unconditionally.
- [ ] `./fvmux -version` prints the version string and exits 0.

## Prefix-key dispatch

- [ ] `Ctrl-G c` opens a second window.
- [ ] `Ctrl-G Ctrl-G` while `cat -v` runs in the focused pane prints `^G`.
- [ ] `Ctrl-G ?` opens the cheatsheet modal listing all bindings.
- [ ] An armed prefix that receives no second keystroke within 2s
      discards itself silently.

## Window management

- [ ] Title-bar drag moves the window.
- [ ] Corner-resize handle resizes the window.
- [ ] `Ctrl-G n` cycles to the next window.
- [ ] `Ctrl-G p` cycles backwards.
- [ ] `Ctrl-G &` closes the focused window and kills its panes.

## Layout

- [ ] `Ctrl-G %` splits the focused pane side-by-side.
- [ ] `Ctrl-G "` splits stacked.
- [ ] `Ctrl-G x` closes the focused pane; closing the last pane closes
      the window.
- [ ] `Ctrl-G z` zooms; second press restores.
- [ ] `Ctrl-G h/j/k/l` navigates panes by direction across nested splits.
- [ ] `Ctrl-G { / }` swaps the focused pane with its neighbour.
- [ ] `Ctrl-G !` detaches the focused pane into a new window.
- [ ] Splitter mouse-drag changes the ratio; release commits.

## UI surfaces

- [ ] Menu bar visible at top.
- [ ] Status bar visible at bottom with `[session]` left and clock right.
- [ ] `Ctrl-G P` opens the fuzzy command palette; typing filters; Enter
      executes; Esc cancels.
- [ ] `Ctrl-G T` opens the theme picker; switching changes colours.

## Session persistence

- [ ] `./fvmux -session=work` with no prior `work.toml` opens fresh.
- [ ] `Ctrl-G S` saves the current layout to
      `~/.config/fvmux/sessions/work.toml`.
- [ ] Quitting via `Ctrl-G : Quit` (or menu File → Quit) auto-saves.
- [ ] Restarting `./fvmux -session=work` restores window positions and
      layouts.

## Connections

- [ ] `Ctrl-G H` opens the host picker showing `~/.ssh/config` entries.
- [ ] Selecting a host opens a new window running `ssh <alias>`.
- [ ] `Ctrl-G B` prints the path to `hosts.toml`.

## SFTP

- [ ] `Ctrl-G F` opens the host picker; selecting a host opens a tree of
      the remote home directory.
- [ ] Expanding a directory lazy-loads its contents.

## Clipboard

- [ ] `Ctrl-G [` shows the focused pane's scrollback in a dialog.
- [ ] `Ctrl-G ]` pastes the OS clipboard into the focused pane.

## Cleanup

- [ ] Quitting fvmux returns the terminal to the outer tmux cleanly.
- [ ] All child PTYs are stopped (`ps` shows no orphaned shells).
